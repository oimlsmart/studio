## What the Studio is

SMART Studio is the tool for viewing and authoring OIML SMART
Recommendations: the surface where an expert reads and shapes a modelled
Recommendation, and the model itself is the published artifact. It comes
in two surfaces:

- **The viewer** at [/studio/view](/studio/view) is public and read-only:
  the published OIML R 60 package rendered as a navigable tree, with the
  canvas, the code view, the mapping lenses, the diff, and validation. No
  account, nothing to install.
- **The editor** at [/studio/edit](/studio/edit) is the full authoring
  surface: the same Studio mounted for editing, with the palette, the
  New/Save/Import actions, and the editable inspector. Edits stay local to
  your browser; nothing writes back to the published model.

## Read your first model (five minutes)

1. **Open the viewer.** The bundled OIML R 60 package (load cells, the
   pilot SMART Recommendation) loads on entry.
2. **Walk the tree.** The model renders as a navigable tree: the roles,
   the processes, the requirements. Click any element to inspect its
   properties in the inspector.
3. **Read the source.** The code view shows the same model as Primmel
   text, the language the packages are authored in; the tree and the text
   are two renderings of one model.
4. **Check the model.** Validation runs in the Studio and reports against
   the package itself, the same verdict the build's gates compute.

## Try the editor

Open [/studio/edit](/studio/edit) and make a change: create an element
from the palette, edit a property in the inspector, and watch the
validation badge answer. Import a `.prl` file of your own, and save the
result back out. The Studio works on local files; the published packages
change only through the packages repository.

## Where authoring is documented

The pipeline for authoring a SMART Recommendation, the methodology,
subjects, requirements, tests, forms, packaging, and walkthroughs, is
documented once, in the [SMART Recommendations
corpus](https://www.oimlsmart.org/recs/docs/). The next guide here,
[Primmel Studio](/studio/docs/guides/primmel-studio), is the editor's
deep dive: the program palettes, the certificate preview, the seven-step
authoring loop, and the review discipline.
